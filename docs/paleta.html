Roles

RolColorQué es
Primario #2152FF El color de la marca. El que más se ve: CTAs y acentos.
Secundario #1B45D6 Variante del primario. No es otro color de marca; es el mismo azul más oscuro.
Neutro #111827 Texto principal. No es un acento; estructura la UI.
Neutro muted #6B7280 Texto secundario. Menos peso visual que el neutro.
Éxito #16A34A Estado positivo. No se usa como marca, solo como semántica.
Advertencia #D97706 Estado de espera o alerta. Tampoco es marca.
Fondos: claro #F7F8FC (mobile / admin light) y oscuro #0A1322 (admin / TV). No cuentan como color de marca; son el lienzo. En superficies oscuras el acento claro es #7EA2FF para que el primario se lea sobre negro.
